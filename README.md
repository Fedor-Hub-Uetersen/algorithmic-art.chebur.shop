# algorithmic-art.chebur.shop
# 🎨 Алгоритмический Портретизм

Веб-галерея цифрового искусства, объединяющая строгую логику программирования, математические алгоритмы векторной графики и теплоту реальных семейных воспоминаний.

🔗 **Официальный сайт проекта:** [algorithmic-art.chebur.shop](https://algorithmic-art.chebur.shop)

---

## 📌 О проекте
«Алгоритмический Портретизм» — это авторская летопись в цикле кода. Каждая работа представляет собой гармонию геометрии, цвета и памятных жизненных сюжетов, переведенных в цифровой формат.

## 🛠 Технологии
* **HTML5 / CSS3** — адаптивная верстка, кастомные CSS-переменные, поддержка темной и светлой темы.
* **JavaScript** — интерактивное открытие изображений в модальном окне и управление интерфейсом.
* **GitHub Pages** — быстрый и надежный хостинг для публикации проекта.

## 📂 Структура галереи
Проект устроен максимально просто и надежно: все графические работы подгружаются напрямую из файлов формата `.png` (`photo1.png`, `photo2.png` и т.д.), размещенных в корне репозитория.
